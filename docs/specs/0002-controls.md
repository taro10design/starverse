# 0002 操作

## 目的

スマホでも PC でも、迷わず光を動かし、星を灯して結べるようにする。
ドラッグやマルチタッチができない人・環境でも同じことができるよう、ドラッグ以外の代替手段を必ず用意する（WCAG 2.2 の 2.5.7 ドラッグ操作の代替）。

## やらないこと

- 文字入力を伴う操作（言葉の機能が無いため）。
- ブラウザや OS のショートカットの上書き。Ctrl / Alt / Meta つきのキーは扱わない（もどす・やりなおすを除く）。
- ブラウザ標準のピンチズーム。`user-scalable=no` で止め、アプリ内のズーム（0.05〜100 倍）に任せる。

## ドラッグ以外の代替手段（WCAG 2.2）

| ドラッグでする操作 | 代替 |
| --- | --- |
| 視点の移動（パン） | 矢印 / WASD、ミニマップのタップ、◎ で光に戻る |
| ズーム（ピンチ） | ＋ − ボタン、+ − キー、ホイール |
| 星を連続で置く | 1 回ずつタップして置く |
| 星を消す・幽霊を忘れる（なぞる） | 1 つずつタップ |

線を引く操作だけはドラッグが必要で、代替が無い。これは既知の不足であり、別の仕様として扱う（リスク参照）。

## リスク

- 線を引く操作に、ドラッグ以外の代替が無い。
