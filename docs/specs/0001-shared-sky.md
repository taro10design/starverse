# 0001 共有の空

## 目的

遠くにいる人どうしが、同じ空を同時に見て、言葉を使わずに「誰かがいる」ことだけを感じられるようにする。
複数の端末から同じ空を開くと、互いの光が見える。光で星を灯し、線で結び、消すことができ、消した自分の星は幽霊として残る。

## やらないこと

- 言葉の機能（チャット、名前、コメント、リアクション文）。意図的に作らない。伝わるのは光・星・線・きらめきだけ。
- アカウント、ログイン、パスワード。持ち主は端末（ブラウザ）ごとの `uid`。
- 星や線の永続保存の保証。共有の空の星は寿命で消える（ひとりの空を除く）。

### 星の寿命（shared/rules.ts）

周囲（半径 `CROWD_R` = 0.06）にある他の星の数で決まる。サーバーとクライアントが同じ関数 `ttlFor` を使う。

| 周囲の星の数 | 寿命 |
| --- | --- |
| 0〜1（孤立） | 3 時間（`STAR_TTL`） |
| 2〜4 | 30 分 |
| 5〜7 | 5 分 |
| 8 以上（密集） | 1 分 |

| # | 条件 | 確認 |
| --- | --- | --- |
| 14 | 孤立した星は 3 時間まで生きる | world.test「孤立した星は STAR_TTL まで生きる」 |
| 15 | 密集した星は 1 分で消え、つながる線も消える | world.test「密集した星は1分で消える」「消えた星につながる線も消える」 |
| 16 | 線は作ってから 3 時間（`STAR_TTL`）で消える | 手動（world.ts の prune） |

### 上限とスパム対策（server/src/config.ts）

| 項目 | 値 |
| --- | --- |
| 空全体の星 / 線 | 500 / 600（`maxStars` / `maxLinks`） |
| 1 人あたりの星 / 線 | 64 / 96（`maxStarsPerUser` / `maxLinksPerUser`） |
| 1 メッセージの大きさ | 512 バイトまで（`maxMessageBytes`） |
| 座標 | 絶対値 10,000 まで（`coordMax`） |

| # | 条件 | 確認 |
| --- | --- | --- |
| 17 | 1 人あたりの上限を超えると星を置けない。消すと枠が空く | world.test / e2e「1 人あたりの星の上限(64)を超えない」 |
| 18 | 全体の上限を超えると星を置けない | world.test「全体の上限を超えると置けない」 |
| 19 | 範囲外の座標・不正な型・大きすぎるメッセージは無視され、接続は保たれる | validate.test / e2e「不正な入力のあとも接続が保たれる」 |
| 20 | 操作が多すぎる接続はレート制限で捨てられ、連続 200 回を超えると切断される（詳細は 0003） | rate-limit.test |

## インターフェース

- 画面: 光（自分）、他人の光、星、線、幽霊、ミニマップ、ヘルプ。操作は [0002](0002-controls.md)、通信は [0003](0003-realtime-protocol-and-scale.md)。
- 色: 8 色のパレット（`PALETTES`）。サーバーは 0〜15 の整数を受け付け、範囲外は 0 にする。
- 近い星どうしは星座として線で結ばれて見え（距離 0.1 未満）、さらに近い 2 つ（0.032 未満）は連星になる。これは見た目だけで、サーバーの線とは別。

## リスク

- 星は孤立していても 3 時間で消える。「残したい」人にはひとりモードを案内する。
- 星は誰でも消せる。荒らしへの対策は、密集の早期消滅と上限であり、完全には防げない。
- uid は鍵リンクを知る人なら誰でも使える。リンクの扱いは利用者に任せる。
