## エッジのレート制限ルールの設定手順

同じ接続元（IP）ごとの制限は、Worker ではなく Cloudflare のエッジで行う（[ADR 0009](adr/0009-prefer-proven-components.md)）。公式: <https://developers.cloudflare.com/waf/rate-limiting-rules/>、ダッシュボードの手順: <https://developers.cloudflare.com/waf/rate-limiting-rules/create-zone-dashboard/>

公式ドキュメントで確認できたこと（2026-10-17 時点）:

- ダッシュボードの **Security rules** → **Create rule** → **Rate limiting rules**。項目は、ルール名、式（Field / Operator / Value）、**With the same characteristics**（カウンターを分ける単位）、**When rate exceeds**（リクエスト数と期間）、**Then take action**（Block など）、**Duration**（制限を続ける時間）
- Free プランの上限: ルールは **1 つ**、カウントの期間は **10 秒**、制限を続ける時間（mitigation timeout）も **10 秒**。数える単位は IP
- カスタムの応答（ブロック時）は Pro プラン以上

設定するもの（案）:

1. ルール 1 つ（Free でも入る）。式は `/ws` への接続だけに絞る。例: URI Path が `/ws` に等しい（接続はアップグレードのリクエスト 1 回なので、メッセージの数ではなく、接続の回数を数えることになるはず。要確認）
2. 数える単位は IP（Free ではこれだけ）
3. 回数と期間: 期間は 10 秒（Free ではこれだけ）。回数は、同じ家庭・会社の NAT の内側の複数人が入れる余裕を見て決める（例: 10 秒あたり 20 回。**数字は未検証で、本番で様子を見て決める**）。再接続の待ちは最小 1.5 秒の指数バックオフ、1008 で切られたあとは 30〜45 秒（`client/src/network.ts`）なので、通常の再接続では引っかからない見込み
4. アクション: Block。続ける時間: Free では 10 秒

要確認（公式ドキュメントで確認できなかったこと）:

- 現在の公開先は `*.workers.dev`（Worker）と `uchu.pages.dev`（Pages）。レート制限ルールはゾーン（自分のドメイン）に付けるもので、`workers.dev` / `pages.dev` のホスト名に効くかは確認できなかった。効かなければ、独自ドメインをゾーンに追加して Worker に割り当てる必要がある
- WebSocket のアップグレードのリクエストがレート制限の対象として数えられるか。1 つの接続の中のメッセージが数えられないことも、ドキュメントには書かれていなかった
- プランごとの最新のルール数・期間（上の値はドキュメントを読んだ時点のもの）。デプロイ後にダッシュボードでプランと使用量を確認する

## 開発環境メモ

- **OneDrive 配下にリポジトリを置かない**ことを推奨する（例: `C:\dev\job-hunting`）。このリポジトリは OneDrive 配下にあり、Node の再帰削除（`fs.rmSync` / `fs.rm`）がネイティブのクラッシュ（終了コード 127、`0xC0000409`）を起こす。一時フォルダでは起きない。Vite の出力先の掃除、`wrangler` の一時ファイル処理などが同じ原因で落ちた。回避策として、ビルド前の掃除は `rimraf`（ファイルを 1 つずつ削除する）にしている（`npm run build` の `prebuild`）
- `wrangler dev` を起動したままビルドしない。`client/dist` を監視している
- `wrangler dev` が、バナーの直後に何も出さず終了することがあった。`.wrangler/cache` と `.wrangler/tmp` を消すと直った（上の OneDrive の問題と同じ原因の可能性が高い）
- ブラウザの検証用タブが非表示だと、画面サイズが 0 になり、描画ループ（rAF）が動かない。ロジックは手動でフレームを進めて確認する
- typescript-eslint は TypeScript 6.1 未満が対象。TypeScript は 6.0 系に揃えている
