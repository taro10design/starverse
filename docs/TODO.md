## 開発環境メモ

- **OneDrive 配下にリポジトリを置かない**ことを推奨する（例: `C:\dev\job-hunting`）。このリポジトリは OneDrive 配下にあり、Node の再帰削除（`fs.rmSync` / `fs.rm`）がネイティブのクラッシュ（終了コード 127、`0xC0000409`）を起こす。一時フォルダでは起きない。Vite の出力先の掃除、`wrangler` の一時ファイル処理などが同じ原因で落ちた。回避策として、ビルド前の掃除は `rimraf`（ファイルを 1 つずつ削除する）にしている（`npm run build` の `prebuild`）
- `wrangler dev` を起動したままビルドしない。`client/dist` を監視している
- `wrangler dev` が、バナーの直後に何も出さず終了することがあった。`.wrangler/cache` と `.wrangler/tmp` を消すと直った（上の OneDrive の問題と同じ原因の可能性が高い）
- ブラウザの検証用タブが非表示だと、画面サイズが 0 になり、描画ループ（rAF）が動かない。ロジックは手動でフレームを進めて確認する
- typescript-eslint は TypeScript 6.1 未満が対象。TypeScript は 6.0 系に揃えている
